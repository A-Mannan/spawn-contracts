- [ ] 5.3 Implement the optional dev buy inside the same unlock, swapping against the freshly minted curves on ordinary buyer terms; verify unit tests covering `token-launch` scenarios "Dev buy consumes bonding curve inventory", "Dev buy is capped below the bonding curve share", and "No dev buy is the default"
- [ ] 5.4 Implement hook-held linear dev-buy vesting with a creator-only release path; verify unit tests covering "Vested tokens are held by the hook", "Linear release over the vesting period", "Full release after the vesting period", "Zero vesting releases immediately", and "Only the creator can claim vested tokens"
- [ ] 5.5 Implement the `beforeAddLiquidity` / `beforeRemoveLiquidity` guards admitting only hook-initiated operations, in every phase; verify unit tests covering `bonding-curve-phase` scenarios "External liquidity addition is rejected", "External liquidity removal is rejected", "Hook-initiated liquidity operations succeed", and "No just-in-time LP exposure during fundraising"

## 6. Dynamic fee and anti-snipe
